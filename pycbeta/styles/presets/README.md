# 内置预设库（随包分发，入库）

CSS 编辑器顶部的"预设"下拉从这里 + 仓库根 `css-presets/`（用户预设，不入库）
合并列出；同名用户预设遮蔽内置。

## 文件格式

自包含完整 CSS = 出厂 `../pdf_docx.css` 原文 + 编辑器覆盖块
（只含字体四属性），可直接 `--theme <本文件>` 用。

## 加新内置预设

1. 编辑器里调好 → 顶部预设行"另存为预设"先存用户目录验证；
2. 满意后把文件拷进本目录（英文名 + `.css`），随包提交。
