# 内置预设库（随包分发，入库）

CSS 编辑器顶部的"预设"下拉从这里 + 仓库根 `css-presets/`（用户预设，不入库）
合并列出；同名用户预设遮蔽内置。

## 文件格式

只存覆盖块（编辑器源码页文本），不存出厂快照。加载时出厂 + 覆盖合并
（层叠后胜；`theme_file_text`），出厂进化自动跟随。旧全快照同样兼容
（重复规则值一致），但新预设一律只存块。

## 加新内置预设

1. 编辑器里调好 → 顶部预设行"另存为预设"先存用户目录验证；
2. 满意后把文件拷进本目录（英文名 + `.css`），随包提交。
