# 安装说明

> 环境：Windows + Python 3.13/3.14（开发机为 3.14）。下述命令均在仓库根目录执行。

## 1. Python 库安装

```bash
pip install -r requirements.txt
playwright install chromium   # PDF 默认引擎（见第 2 节）
```

| 包 | 用途 | 缺失后果 |
|---|---|---|
| `lxml` | XML 解析（核心） | 不可运行 |
| `tinycss2` | 主题 CSS 解析（核心） | 不可运行 |
| `fontTools` | 字体 cmap（`--font-check`、补充字形注音） | 检测跳过、自动注音降级 |
| `playwright` + `playwright install chromium` | PDF 默认引擎 | `-f pdf` 默认链失败，改走其他引擎 |
| `PySide6` | GUI 独立窗/面板 | `python -m pycbeta.gui` 不可运行 |
| `pypinyin`（可选） | 生僻字自动注音 | 缺字跳过，手动词表不受影响 |
| `pymupdf`（可选，仅开发） | PDF 冒烟测试 | 测试跳过 |
| `pywin32`（可选） | Word/WPS COM 导出 PDF | 这两个后端自动跳过 |
| `weasyprint`（可选） | HTML→PDF 备选引擎，另需 GTK/Pango 运行时 | 该引擎不可用 |

## 2. PDF 引擎安装（二选多装，装一个即可出 PDF）

默认链（`config.json → engines`）：`docx2pdf: msword → wps → docbuilder → libreoffice → minipdf`，
`html2pdf: chromium → cbetapdf`。按链顺序首个成功者出 PDF；`--engine 管线:单体` 可强制单个。

| 引擎 | 安装 | 验证 |
|---|---|---|
| chromium（默认首选） | `playwright install chromium` | `--engine html2pdf:chromium -f pdf …` |
| MS Word（msword） | 安装 Office + `pip install pywin32` | `--engine docx2pdf:msword …` |
| WPS（wps） | 安装 WPS Office + `pip install pywin32` | `--engine docx2pdf:wps …` |
| LibreOffice | 安装后把路径填 `engines.paths.libreoffice`（如 `C:\Apps\LibreOffice\program\soffice.com`）；安装前先 `taskkill /F /IM soffice.bin`（常驻进程锁目录） | `soffice.com --version`；`--engine docx2pdf:libreoffice …` |
| ONLYOFFICE DocBuilder | 安装后填 `engines.paths.docbuilder` | `--engine docx2pdf:docbuilder …` |
| minipdf / cbetapdf | 随包 `engines/*.exe`，开箱即用（minipdf 官网：https://github.com/mini-software/MiniPdf） | 链尾兜底 |
| prince | 安装 Prince 并进 PATH | `--engine html2pdf:prince …` |
| weasyprint | `pip install weasyprint` + GTK/Pango 运行时 | `--engine html2pdf:weasyprint …` |

GUI 里输出格式卡的"单引擎"下拉会自动探测本机已装项（未安装标红并提示去哪装）；
`--engine-tag` 可把实际使用的引擎名追加进 PDF 文件名（如 `X60n1116_wps.pdf`）。

自定义外部引擎：`config.json → engines.external` 注册 `{executable, arguments, timeoutSeconds}`，
`{input}`/`{output}` 为占位符，加入对应 `chain` 即可（README 有完整示例）。

## 3. 字体安装（可选，但影响豆腐字）

- 正文/标题走系统字库；缺字（`>0xFFFF`）按 `output.docx.gaijiFonts` 链取本机已装首个
  （繁：补充字形；简：SimSunExtB → 补充字形）。
- 建议安装：`cbeta/fonts/CBETASupplement.ttf`（双击安装；装后 ExtB/F 缺字有 fallback），
  生僻字建议装 SimSun-ExtB（一般随系统自带）。
- 查本机有什么名可填：`python -m pycbeta.cli --list-fonts "kaiti"`（中英文关键词都认，
  第一列即 `font_sets` 里要填的 GDI 名）；查缺字：渲染加 `--font-check`。

## 4. 命令行参数

```
-i INPUT           XML 文件/目录/佛典編號（T0349…；缺 XML 自动从官方下载）
-o OUTPUT          输出文件或目录（默认源目录同名）
-f FORMAT          html,pdf,docx,md,epub（逗号）或 all
--theme            自定义主题 CSS/JSON（替换 pdf_docx.css；html 在官方基底上追加）
--font-set 组合:语言  字体方案（如 :zh-Hans 切简体字库，只换字库不转文字）
--t2s / --no-t2s   OpenCC 简体输出（默认联动简体字库；校验时基线同步转简体）
--font-scale 1.5   字号等比缩放（大字版 1.33/1.5；不影响校验）
--config           自定义全局配置（别名 --presets-file；复制 pycbeta/config.json 改）
--page             页面方案（a4/a5/letter/phone/tablet/monitor/book）
--notes            footnote/endnote/inline（默认 docx=footnote，其余=endnote）
--engine 管线[:单体]  PDF 路径，见第 2 节；--vertical 竖排走 HTML 管线
--engine-tag       PDF 文件名追加实际引擎名
--xml-dir / --download-dir  本地 XML 源 / 官方下载落盘（默认 config source.*）
--name-template    输出文件名模板（[id][书名][作者][vol][juan]）
--verify [--verify-max-diff N] [--verify-diff-lines N]
                   生成后逐字校验（对比官方文档；阈值 缺+多≤N，默认 10/5）
--font-check       豆腐字检测（逐字覆盖率报告 TOFU/SUP/FB/MISS，不中断渲染）
--list-fonts [关键词]  列出本机字体（家族名|路径），仅列表不渲染
```

## 5. GUI 使用

```bash
python -m pycbeta.gui
```

- 七选项卡：输出格式 / 页面 / 分页 / 排版 / 注释 / 注音 / 校验
  （输出格式首位，内含字体区；分页含佛典丛书名；注音为常用六项）。
- 顶部"配置"框：`保存到配置`（当前槽 `config.user.json`，旧值轮换进 `config.last.json`）、
  `还原出厂`（回 `pycbeta/config.json`，同样可再撤销一次）。出厂文件 GUI 永不写。
- 独立窗：目录/文件 或 佛典編號列表两种输入，☐自动下载缺失 XML / ☐同时下载官方基线；
  批量表显示经号/经名/来源/状态，文件列单击打开产物；开始/取消 + 总进度。
- publish 侧集成见 `docs/第三方调用说明.md` §6.1。

## 7. 常见问题

- **控台中文乱码**：Windows gbk 控台打不出 ExtB/G 生僻字与拼音声调，程序内已降级显示；
  完整内容看落盘文件（`font-check-<id>.txt`、verify `report.txt` 均为 UTF-8）。
- **首次运行慢**：冷盘 + Defender 扫描 + Python 预热，第二次即正常；与功能开关无关。
- **LibreOffice 升级/改路径**：同步改 `engines.paths.libreoffice`，安装前先杀常驻 `soffice.bin`。
- **WPS 看不见 w:ruby 上方注音**：WPS 只认自家 EQ 域，注音 `style` 改 `field`
  （`ruby_up` 默认 100% 正文字号防相交）；LibreOffice 下用 `inline`。
- **`--font-set :zh-Hans` 只换字库不转文字**，转文字用 `--t2s`。
