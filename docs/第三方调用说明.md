## 2. 下载模块 `pycbeta/fetch.py`（GUI 最常用）

> **共享下载层**：作品 URL 模板 / work id 大小写规范化 / catalog 查表 / 下载与 zip 解压 /
> 条件更新，已抽到独立仓库 **`cbeta-fetch`**（纯标准库），本仓库以 vendored 副本
> `pycbeta/_vendor/cbeta_fetch.py` 复用（`from pycbeta._vendor import cbeta_fetch`）。
> `fetch.py` 的 `is_work_id`/`parse_work_id`/`canonical_work_id`/`catalog_lookup`/
> `_http_download`/`_unzip_flat`/`_download_if_changed` 均为其薄封装，签名/行为不变。
> 同步：`python <cbeta-fetch>/tools/sync_into.py pycbeta/_vendor`；`test_vendor_sync` 校验 sha256。
> `update_data.py` 的元数据 URL 也已单源到 `cbeta_fetch.REMOTE_URLS`（`remote_sources.json`
> 可省略 url、用 `"source"` 引用）。

### 2.1 `is_work_id(s: str) -> bool`
校验 CBETA 佛典編號（`T0349`/`T0099`/`A1057`/`X1271`/`T0128a`/`TXa001`）。大小写不敏感（字母后缀原始大小写由 catalog 决定，见 2.3b）。
```python
from pycbeta.fetch import is_work_id
is_work_id("T0349")   # True
```

### 2.2 `parse_work_id(work_id: str) -> tuple` → `(canon, no)`
```python
from pycbeta.fetch import parse_work_id
parse_work_id("X1271")   # ('X', '1271')
```

### 2.3 `catalog_lookup(catalog: str, canon: str, no: str) -> List[Dict]`
读 `sutra_mapping.txt`（列 `canon,vol,no,…`），返回 `[{"vol":"12","no":"0349","file":"T12n0349.xml","title":…}]`，**多冊特例全返**（X0714→X39+X40、T0220→T05/06/07）。
**canon/no 大小写不敏感**匹配（catalog 字母后缀大小写不统一：`TX,00,a001`、`T,02,0128a`、`J,15,B005`），返回值用 **catalog 原始大小写**（`no`/`file`）——CBETA XML 文件名与电子书端点大小写敏感。
```python
from pycbeta.fetch import catalog_lookup
catalog_lookup(r"…\cbeta\data\sutra_mapping.txt", "T", "0349")
# [{'vol': '12', 'no': '0349', 'file': 'T12n0349.xml', 'title': …}]
catalog_lookup(cat, "TX", "A001")     # 命中 TX,00,a001 → file TX00na001.xml
```

### 2.3b `canonical_work_id(work_id, presets=None) -> str`
按 catalog 原始大小写规范化编号（canon 大写 + no 原样：`txa001/TXA001 → TXa001`、`T0128A → T0128a`、`JB005 → JB005`）；catalog 未命中（离线/本地/未知）原样返回。`materialize_work`/`fetch_work`/`ensure_baselines`/`ensure_figures`/`check_ebook_updates` 内部已调用，故**编号大小写打错也能下对** XML 与电子书。
> catalog 钉死内置：`fetch.resolve_catalog(value)`（相对值按仓库根解析，绝对值/空一律回
> `builtin_catalog()` 即程序内 `cbeta/data/sutra_mapping.txt`）；presets 的 `source.catalog`
> 不再被查阅（旧预设残留键忽略）。`catalog_lookup(path, …)` 纯函数签名不变，直调仍可用任意路径。

### 2.4 `find_local_xml(xml_dir: str, canon: str, no: str) -> List[str]`
本地 XML 候选源查找 `{canon}*n{no}.xml`（排除 `out/`）。统一根目录下两档：平展优先（根下 `work id` 开头条目内），仓库次之（全树递归，兼容 CBReader 碎片布局）。
```python
from pycbeta.fetch import find_local_xml
find_local_xml(r"E:\CBETA\CBReader2X\Bookcase\CBETA\XML", "T", "0349")
# ['...\\T\\T12\\T12n0349.xml']
```

### 2.5 `fetch_work(work_id, formats, presets=None, cbeta_ebook=None) -> Dict[str, List[str]]`
下载一部经的多格式；返回 `{fmt: [路径]}`，**失败格式为 []（静默，不抛异常）**。
`formats ∈ {xml, html, docx, epub, txt_notes, odt}`（官方 plain `text` 已弃用）。
```python
from pycbeta.fetch import fetch_work
from pycbeta.theme import load_presets
res = fetch_work("T0349", ["xml", "html", "docx"], load_presets(),
                 cbeta_ebook=r"E:\dev\cbeta\cbeta_ebook")
print(res["xml"])    # ['...\\cbeta_ebook\\T0349 彌勒菩薩所問本願經\\T12n0349.xml']
print(res["docx"])   # docx/odt 非 T/X 藏经时 → []
```
落盘约定（2026-09-11 起，`cbeta_ebook` 为唯一可写工作根）：
- work 目录 `{cbeta_ebook}/{id} {书名}/`（书名取 catalog，经 `source.title_t2s` 转简 + 文件名净化；已有 `{id}*` 目录复用）
- XML → work 目录根（多册部：每册一个文件，如 `TX07n0006.xml`）
- 基线 → work 目录下**格式同名子目录**、**平展**（`html/`、`docx/`、`epub/`、`odt/`、`txt/`＝text-with-notes）；zip 解压后即删（不留 zip、不保留 zip 内部目录层次）
- 任一文件已有都不重复下载；docx/odt 官方仅 T/X 提供，404 静默跳过。

### 2.6 `materialize_work(work_id, presets=None, xml_dir=None, cbeta_ebook=None, download=True, quiet=False) -> (List[str], str)`
编号流**三源材料化**：`cbeta_ebook`（已材料化）→ `xml_dir`（只读候选源：整文件拷贝 / 碎片按册合册）→ 官方下载。
返回 `(work 目录内 XML 路径列表, 来源标签)`，标签 ∈ `cbeta_ebook / xml_copy / xml_merge / downloaded / ""`。
本地源刷新：xml_dir 源文件比 work 目录副本新时重拷/重合力（mtime 判定）。
`xml_dir` **建议指向本地下载的 `cbeta-org/xml-p5` 全仓库副本（发布版 P5）**；勿指 CBReader（P5a/P5b 编码不同，正文/校勘渲染不完整）。
```python
from pycbeta.fetch import materialize_work
paths, label = materialize_work("TX0006", load_presets(),
                                xml_dir=r"E:\dev\cbeta\xml-p5",
                                cbeta_ebook=r"E:\dev\cbeta\cbeta_ebook")
# paths: 3 个文件（TX07/08/09n0006.xml）；label: "xml_merge"
```

### 2.6b `inspect_xml_source(xml_dir, sample=5) -> Dict`
抽检本地候选源 TEI 版本（读文件头 `<edition>`）：返回 `{"safe": True|False|None, "edition", "sample", "reason"}`。
仅 `XML TEI P5` 判 `safe=True`；`P5a/P5b` 判 `False`（GUI 据此告警/清除，CLI 据此打印警告后继续）；目录空/无 XML 判 `None`；缺 `<edition>` 按 P5（`True`）。

### 2.7 `ensure_baselines(work_id, kinds, presets, cbeta_ebook) -> Dict[str, List[str]]`
校验用：仅下载**缺失**的基线格式，返回本次新获取 `{kind: [路径]}`（已存在跳过）。落 work 目录。
```python
from pycbeta.fetch import ensure_baselines
ensure_baselines("X1116", ["docx", "html"], load_presets(),
                 r"E:\dev\cbeta\cbeta_ebook")
```

### 2.7b `ensure_figures(work_id, urls, presets=None, cbeta_ebook=None, wdir=None) -> (ok_paths, missing)`
图片预取（`<graphic url="../figures/{canon}/{file}">`）：缺的下到 `{work}/figures/`。
顺序：`figures/` 已有 → `{work}/txt/` 基线 bonus 拷贝 → 远端 `downloads.figures`
模板（`https://raw.githubusercontent.com/cbeta-git/CBR2X-figures/master/{canon}/{file}`）。
404/失败只记缺失、不抛错。`materialize_work` 与 `ensure_baselines` 在 XML 含 `<graphic>` 时自动触发；
纯函数见 `pycbeta/figures.py`（`split_graphic_url/find_figure/search_dirs/graphic_urls_in_text/gif_size`）。
```python
from pycbeta.fetch import ensure_figures
ok, missing = ensure_figures("X1077", ["../figures/X/X59p0224_01.gif"],
                             load_presets(), r"E:\dev\cbeta\cbeta_ebook")
```

### 2.8 配置依赖
`config.json`：
- `source`：`xml_dir`（本地 XML 候选源，只读；不得与 `cbeta_ebook` 相同）、`cbeta_ebook`（电子书输出目录，唯一可写）、`catalog`（仓库相对路径，钉死内置，见 §2.3b 注）、`title_t2s`（工作目录名书名转简，默认 true）
- `downloads`：7 个 URL 模板（`xml/html/docx/epub/txt_notes/odt/figures`），占位符 `{canon}/{vol}/{id}/{file}`
- 官方数据更新（`update_data`）：`DISPLAY_NAMES`（更新源中文名，GUI 共用）、`source_rows()`（GUI 表格行）、`update_all()`（同步落盘，CLI `--update-data` 同源）

### 2.9 `check_ebook_updates(cbeta_ebook, presets=None, probe=None, progress=None, with_baselines=True) -> List[Dict]`
远程源更新检查：遍历 `cbeta_ebook` 各 work 目录，对 catalog 记录的每册 XML 做**条件下载**
（本地已有则带 `If-Modified-Since`，304 免下载；否则比对字节），**不改项不落盘**（无 sidecar，按日期/体积判定）。
**只走远程源（远程永远最新）；不读本地 `xml_dir` 候选源**（本地 `xml_dir` 仅用于材料化首次导入，不参与更新；建议指向本地下载的 `cbeta-org/xml-p5` 全仓库副本＝发布版 P5，勿指 CBReader P5b）。
`with_baselines=True`（默认）：XML 有更新的 work，其**本地已有的基线**（html/docx/epub/txt/odt，仅已存在格式）强制刷新，并**补拉缺失的 `txt_notes`**（文本族必备）。
`probe(url, dest) -> (status, detail)` 与 `progress(id, done, total)` 可注入（单测）。
`format_update_report(report)` → 文本行（含「需重新生成电子书」ID 段，供 GUI/CLI）。
```python
from pycbeta.fetch import check_ebook_updates, format_update_report
rep = check_ebook_updates(r"E:\dev\cbeta\cbeta_ebook", load_presets())
print("\n".join(format_update_report(rep)))
```
GUI：数据源窗口「更新XML」按钮（后台线程）+ 结果弹窗，可**一键拷贝已更新 ID**。

## 3. 配置装载 `pycbeta/theme.py`

### 3.1 `load_presets(path=config.json) -> Dict[str, dict]`
返回顶层字典，键：`theme / pages / engines / docx / output / source / downloads / verify`（支持 `//` 注释）。
```python
from pycbeta.theme import load_presets, resolve_theme_css
p = load_presets()
pages = p["pages"]            # {"a4": {"size":[210,297], "margins":{...}}}
path, label = resolve_theme_css(p.get("theme", ""))  # 默认 CSS（None=内置）
source = p["source"]          # {"xml_dir", "cbeta_ebook", "catalog", "title_t2s"}
```

### 3.2 `resolve_page(name, page_presets=None) -> Dict`
页面方案解析，返回 `{"size": (w_mm, h_mm), "margins": {...}, "latin_font"}`（GUI 纸张下拉的默认值来源）。`latin_font` 缺省回退 `"Calibri"`；文档兜底字号跟主题 base（`Theme.base_pt`），不在此返回；`DocxRenderer(latin_font=…)` 显式值优先，CLI 由主题 `--font-latin` 变量解析传入。

### 3.3 `REQUIRED_THEME_TAGS` / `missing_required_theme(theme) -> List[str]`
主题默认值**唯一定义处 = `styles/pdf_docx.css`**（Python `DEFAULT_THEME` 已移除）。`REQUIRED_THEME_TAGS`（`{标签: 必需属性元组}`）声明出厂 CSS 必须提供的元素/关键属性（`p` 刻意不含 `font-size`：跟随 `body` 单源）；`missing_required_theme(theme)` 返回缺失项文本（空列表=齐全），供测试与工具提示"往 pdf_docx.css 补选择器"。
```python
from pycbeta.theme import Theme, missing_required_theme
assert missing_required_theme(Theme()) == []   # 出厂 pdf_docx.css 齐全
```

## 4. 校验库 `pycbeta/verify.py`（GUI 可选集成）

| 函数 | 签名 | 说明 |
|---|---|---|
| `verify_one` | `(xml_fn, fmt, source, out_root, max_diff=10, diff_lines=5, config_path=None, t2s=False, baseline="render", gen_paths=None) -> Dict` | 单文件校验；返回 `{status: ok/fail/no_baseline/covered/error, missing, extra, total, official, official_kind, ctx, gen, src_cmp, gen_cmp, norm_gen, norm_official, trials}`（`norm_*` 归一化后串；`trials` = 每个尝试过的基线 `{kind,missing,extra,total,ok,ctx,norm_official,...}`；`fmt="pdf"` 直接返回 `no_baseline`，PDF 校验由调用方按 `render_pdf.pdf_source_fmt` 委托源格式或标 `covered`；`gen_paths` 给定则跳过 `generate_formal` 只比对已有文件，全缺失返回 `status="error"`，供 CLI `--verify-only`/GUI 复用） |
| `format_verify_report` | `(records, diff_lines=5, max_diff=10) -> List[str]` | 由 `verify_one` 记录列表生成「验证总报告」行：每个 XML 一段，**逐条列出所有尝试基线** `[OK]\|[FAIL] ({fmt}→{基线kind} 缺X/多Y ≤\|>阈值N)` + `【源】/【新】` 路径 + `【源比较】/【新比较】行号对齐 <cmp 文件名>`；差异条目先出 `N.（源比较第X行，新比较第Y行）` 定位行，再列 `【源】/【新】〖…〗`（行号即 `*_compare_*.txt` 的 TXT 行号，`ctx_loc` 缺失时省略定位行）；对齐 `report.txt` |
| `generate_formal` | `(xml_fn, work, fmt, outdir, config_path=None, overrides=None) -> List[str]` | 正式管线生成（`html` 多文件/其余单文件），返回路径列表；**校验用途恒 `show_notes=True`**（忽略 `output.show_notes`，官方基线含注） |
| `find_official` | `(source, stem, kind, juan=None) -> List[str]` | 官方基线发现（短名回退/`_NNN` 优先/`out/` 排除/卷范围限定 `scope_juan`） |
| `normalize` / `normalize_with_lines` / `diff_stats` | 文本归一 / 带回行映射的归一 / 差异统计 | `missing=官方有而生成档缺失, extra=生成档有而官方多出, total=缺+多`；`ctx_locations`+`_mark_span` 供报告定位 |
| `work_juan_numbers` | `(work) -> set` | XML 实际卷号集合（基线卷限定） |

```python
from pycbeta.verify import verify_one
r = verify_one(r"E:\dev\cbeta\cbeta_ebook\T0349 彌勒菩薩所問本願經\T12n0349.xml",
               "docx", r"E:\dev\cbeta\cbeta_ebook", r"E:\dev\cbeta\cbeta_ebook\out\verify")
# r["status"] == "ok" 且 r["missing"] == r["extra"] == 0
```
校验参数 `verify` 块（`auto_fetch/scope_juan/maxDiff/diffLines/compareInfos`）经 `load_presets()` 读取。

## 5. 渲染器（GUI 批量转换直接可用）

| 渲染器 | 构造要点 | `render_work` 返回 |
|---|---|---|
| `HtmlRenderer` | `notes="endnote", inline_brackets="halfwidth"（正文夹注，对齐官方）, note_inline_brackets（校注内联）, figure_base（图片搜索目录 str|list，缺省占位）` | `List[str]` 按卷文件（`T0625_001.html…`）；有图内嵌 `<img data:…base64>` |
| `DocxRenderer` | `page="a4", notes="footnote", suppress_jhead_dup, show_close_juan, inline_brackets, note_inline_brackets, series_title, pagination, figure_base, latin_font, page_presets` | 单文件 `str`（`split=True` 时列表）；**传 `page_presets` 时构造即按纸张应用 `body_font_size/body_line_height`**（`ensure_page_typography`，`page_presets=None` 或已应用则不动）；RJ 悉昙缺字自动附读音（如 `歾(raṃ)`，取 work charDecl `roman`，走 `latin_font`；`output.show_body_siddham=false` 则正文不显示悉昙字和读音，脚注不受影响）；`cb:tt` 转写行按 `transliteration` 标签着色；有图内嵌 `word/media`（`w:drawing`），缺图出 `【圖：…】`；run 的 `w:rFonts` 西文（`ascii/hAnsi`）走 `latin_font`（缺省 `--font-latin`），`eastAsia` 中文名（**不加 `w:hint`**：否则 ā/ī 等 EAW=A 拉丁字母会落中文字体）；注脚/尾注/内联注释按官方追加 cf 参考 ` (cf. a; b)` |
| `EpubRenderer` | `notes="endnote", inline_brackets, note_inline_brackets, figure_base` | 单文件 |
| `MdRenderer` | `notes="footnote", inline_brackets, note_inline_brackets, show_dharani_transliteration` | 单文件；逐字咒文表（`<cb:tt>` 无 `place="inline"`）转写默认不显示（`show_dharani_transliteration=false`，官方 txt 一致） |
| `TxtRenderer` | `notes, inline_brackets, note_inline_brackets, show_dharani_transliteration` | 单文件；尾注：正文 `[n]` 标记 + 文末 `[n] 内容`（`show_notes=false` 全无）；逐字咒文表（`<cb:tt>` 无 `place="inline"`）转写默认不显示（官方 text-with-notes 一致）；无法表示的悉昙字用 `◇` |

正文夹注（`<note place="inline">`）属原文，**不受 `show_notes` 控制**，用 `inline_brackets`；校注内联（`notes="inline"` 时的脚注/校勘）用 `note_inline_brackets`，`note_inline_brackets=None` 时回退 `inline_brackets`（旧调用行为不变）。括号取值 `theme.bracket_pair(v) -> (左,右)`：`fullwidth（）`/`halfwidth()`/`corner〔〕`/`square[]`，未知回退全角。

注释方式：`theme.resolve_notes(presets, fmt=None, explicit=None) -> "footnote"|"endnote"|"inline"`（`explicit > output.notes（非空合法）> 默认 footnote`）；渲染器 `notes` 参数语义同 CLI `--notes`（html/epub/md/txt 仅区分 `inline` 与否则）。

```python
from pycbeta.parser import P5Parser
from pycbeta.render_docx import DocxRenderer
from pycbeta.filename import default_output_name
work = P5Parser().parse(xml_fn)
# 默认命名与 CLI 一致：{佛典編號 书名}（title_t2s 跟随 source 配置）
name = default_output_name(work.id, work.metadata.get("title"), True) + ".docx"
fn = DocxRenderer(page="a4", pagination={"enabled": True, "duplex": True, "juan": True}
                  ).render_work(work, out_dir, filename=name)
```

## 6. 组合示例（材料化 → 转换 → 校验）

```python
from pycbeta.theme import load_presets
from pycbeta.fetch import materialize_work
from pycbeta.parser import P5Parser
from pycbeta.render_docx import DocxRenderer
from pycbeta.verify import verify_one

presets = load_presets()
ebook = presets["source"]["cbeta_ebook"]

# 1) 三源材料化（cbeta_ebook → xml_dir → 官方下载）
xmls, label = materialize_work("T0349", presets)
xml_fn = xmls[0]

# 2) 转换
work = P5Parser().parse(xml_fn)
DocxRenderer(page=presets["output"].get("page", "a4")).render_work(work, out_dir, "T0349.docx")

# 3) 校验（work 目录内已有基线）
r = verify_one(xml_fn, "docx", ebook, out_root)
assert r["status"] == "ok"
```

### 6.1 佛典編號列表批量流程（GUI 独立窗 / publish bridge 用）

```python
from pycbeta.fetch import is_work_id, materialize_work, ensure_baselines

def prepare_work(work_id: str, presets, fetch_xml: bool = True,
                 fetch_baselines: bool = False) -> list:
    """三源材料化（cbeta_ebook → 本地候选源 → 下载）→（可选）下载官方基线；
    返回 work 目录内 XML 路径列表。"""
    if not is_work_id(work_id):
        return []
    ebook = presets["source"]["cbeta_ebook"]
    xmls, _label = materialize_work(work_id, presets, download=fetch_xml)
    if fetch_baselines and xmls:
        ensure_baselines(work_id, ["html", "docx", "txt"], presets, ebook)
    return xmls
```

对 ID 列表逐项：`prepare_work` → `P5Parser().parse` → 各渲染器 / `subprocess [python -m pycbeta -i xml -f … --page … -o out]` → 可选 `verify_one`。下载失败格式静默（返回 `[]`/空集），由调用方标记行状态。

### 6.2 进程内库调用（publish 链路 B）

```python
from pycbeta.cli import main as cli_main
cli_main(["-i", "T0001", "-f", "pdf", "-o", r"D:\out\T0001.pdf",
          "--config", r"...\presets\我的配置.json",   # 或 run.json
          "--cbeta-ebook", r"D:\cbeta_ebook"])        # 工作根，显式传入
```

- **`--config` 两种模式都吃**：run.json 组合单（5 槽），或基础配置 JSON
  （`config.user.json` / `presets/*.json`，当作 `config-json` 槽，其余槽出厂默认）。
  解析见 `theme.resolve_config_arg(path) -> (run, run_dir)`。
- **XML 工作根**：传 `--cbeta-ebook`（`source.cbeta_ebook`）；本地候选源 `--xml-dir`
  可空。`-i` 只给编号时由 `materialize_work` 三源解析（工作根 → 候选源 → 官方下载）。
- **主题槽**：base 配置不含主题槽，需自定义 CSS 时用 run.json 或显式
  `--pdf-docx-theme/--pdf-docx-user-theme`；`--html-epub-user-theme` 占位（未接线，警告忽略）。
- **面板复用（不碰私有 API）**：
  `XmlOptionsPanel.get_options()/set_options()`、`XmlOptionsPanel.merged_preset(base=None)`
  （面板值+base → 预设 dict）、`XmlOptionsDialog.get_options()/get_preset(base=None)`
  （`exec()` 后取结果）、`list_config_presets/load_config_preset/save_config_preset/delete_config_preset`
  （`presets/` 读写）。预设名非法/目录外删除抛 `ValueError`。

### 6.3 独立窗启动参数预填（publish 一键送校验）

```bash
python -m pycbeta.gui --ids-file <ids.txt> --out <输出目录> [--preset <预设>] \
                      [--formats pdf,epub] --verify --autostart
```

- `--ids-file`：ID 列表文件（publish 把丛书 work_ids 写进校验目录 `*_ids.txt`），
  填入输入来源并切到"目录/文件"（`.txt` 按行取編號）。
- `--out`：输出目录预填（publish 用校验目录，产物与报告落该处）。
- `--preset`：**stem / `*.json` 文件名 / 绝对路径都认**（publish 传的是文件名，
  如 `my.json`），命中即选中下拉并载入面板；不存在则保持原选中（静默）。
- `--formats`：逗号分隔格式（`pdf,epub,…`），预填格式勾选（publish 与右栏勾选对齐）；
  全不匹配时回退 `pdf`。
- `--verify`：勾选"转换后校验"；`--autostart`：窗口出现即开始转换。
- Qt 自带参数透传（`parse_known_args`，其余进 `QApplication`）；无参数时与裸启动一致。
- **CLI `--verify` 亦支持 `-i` 传目录/佛典編號**：目录用扫描到的 XML、編號用
  `materialize_work` 产出的 XML 逐个校验（不再把編號当 XML 路径）。
- **CLI `--verify` 的比对档由 `verify.generate_formal` 另生成**（`verify` 段覆盖 `output`
  段，如 inline_brackets/suppress_jhead_dup/show_close_juan），与独立窗完全一致；不改动实际产物。
- **CLI `--verify-only` 只校验已有产物**：跳过渲染，用 `cli.resolve_output`
  （本轮 `_used_names` 为空→默认命名；dedup 改名过的旧产物可能定位不到）定位既有
  生成档，缺失报 `gen not found` 并计失败（退出码非零）；报告仍落 `{输出}（验证）/`。
  函数侧对应 `verify_one(..., gen_paths=[...])`。
- publish 侧流程（`cbeta_publish`）：丛书非空检查 → 临时预设须已保存 →
  写 ids 文件 → `subprocess.Popen([sys.executable, "-m", "pycbeta.gui", ...], cwd=<x2p>)`
  detached 启动 → 独立窗内跑完校验 → publish 用"导入校验通过项"入库。
  另有不带参数的"打开 xml2pdf 独立窗"入口（纯裸启动）。

## 7. 约定与限制

- `fetch_work`/`ensure_baselines` 下载使用 **unverified SSL**（cbdata 证书缺 SKI，公共数据集可接受）
- docx/odt 官方目前**仅大正藏 T 与《卍續藏》X** 提供，其它藏经 404 → 返回 `[]` 静默
- `verify_one` 的 `auto_fetch=true` 时基线缺失会自动下载（落 `source.cbeta_ebook` 的 work 目录，缺省回退 `source` 参数）
- `requirements.txt` 不含 PySide6（GUI 由 `publish` 侧提供）；若独立窗需 `PySide6>=6.6`

## 8. 参数总览（CLI / GUI / 配置 映射）

> 关键结论：**面板选项写进「基础配置」**（run.json 的 `config-json` 槽文件，即
> `presets/*.json`），CLI 侧由 `resolve_effective_config` 读取，故「面板有、CLI 无同名

### 8.6 对 publish 的含义
- **面板选项 = 配置项**，publish 把面板结果经 `--config` 传入即生效（无需逐个开关）。
- **没有 CLI 开关的项**（表中 ❌/括号）：分页全套、黑白/页框、排版多数、注释多数、
  注音全套、校验的自动下载/按卷、边距/正文、`downloads` 模板、`catalog`、`pdf_zoom` 等，
  **只能经配置**，不能用命令行单独覆盖。
- `engine` / `vertical` / `font_lang`：**已支持配置回退**（见 §8.7），随 `--config` 生效，
  命令行开关仍可显式覆盖。
- 主题槽（4 个 CSS）**不在 base 配置**，需 run.json 或显式 `--pdf-docx-*`。
- `formats` / `-f` 仍必须显式给（缺失即 `ap.error`）。

### 8.7 `engine` / `font_lang` / `vertical`（配置回退 + 开关覆盖）

这三项不在 run.json 的 5 个槽里（5 槽 = `config-json` + 4 个 CSS 主题槽），历史上 CLI
只读命令行。现已在 CLI 主流程加**配置回退**（`cli.resolve_engine_vertical_lang`）：

| 面板项 | 配置键 | 解析优先级 | 开关 |
|---|---|---|---|
| 引擎 | 顶层 `engine` | `--engine` > `presets.engine` > 默认 docx2pdf | `--engine` |
| 竖排 | `output.vertical` | `--vertical` 或 `output.vertical`（逻辑或） | `--vertical` |
| 字库语言 | 顶层 `font_lang` | `--font-lang` > (t2s→`zh-Hans`) > `presets.font_lang` > `zh-Hant` | `--font-lang` |
| 引擎链/单体 | `engines.*.chain` | 一直读配置（`cli.py:554/616/618`） | — |

> 所以 publish 用「临时预设 + `--config`」时，这三项**已随预设生效**，无需再补开关；
> 只有在需要临时覆盖预设时才加 `--engine` / `--vertical` / `--font-lang`。
> （xml2pdf 自身 GUI 批量仍显式传开关，属等价覆盖，显式优先。）

```bash
# 只给预设即可（engine/vertical/font_lang 从预设读）
pycbeta -i T0001 -f pdf -o out/T0001.pdf --config <tmp preset> --cbeta-ebook <工作根>
# 临时覆盖示例：
pycbeta ... --config <tmp preset> --engine html2pdf --vertical --font-lang zh-Hans
```

- `--engine` 取值即面板引擎：`docx2pdf` / `html2pdf`（或 `管线:单体`，如 `docx2pdf:wps`）。
- `--font-lang` 不传时：t2s 优先推 `zh-Hans`，否则取 `font_lang`，再无则 `zh-Hant`。
- `formats` 不走配置：publish 每本用 `-f <fmt>` 指定。

## 9. 临时预设（不改已有预设）

**结论**：用 `XmlOptionsDialog` 调整的选项，必须经**配置**才生效；如果只是临时改动、
不想动 `presets/` 里已有预设，**存成临时预设文件即可**（系统 temp，用后删除），
完全可行，且正是 xml2pdf 自己 GUI 批量桥的做法。

三种载体（按需要选）：

| 场景 | 函数（`pycbeta.gui.panel`） |
|---|---|
| 面板结果 **dict** 直接喂 `--config` | `write_temp_preset(data)` |
| 有 `XmlOptions`（`panel.get_options()`） | `write_temp_presets(base, opts)` |
| 需要整套 run.json（含 4 个主题槽） | `write_temp_run(run, snapshot_path)` |

publish 侧示例（临时改动 → 不改预设、不写 run.json 槽）：

```python
import os
from PySide6.QtWidgets import QDialog
from pycbeta.gui.panel import XmlOptionsDialog, write_temp_preset

dlg = XmlOptionsDialog(base)                 # 预填当前选中预设
if dlg.exec() != QDialog.Accepted:
    return
data = dlg.get_preset(base)                  # 面板值 + base（合并后的预设 dict）
tmp = write_temp_preset(data)                # 落系统 temp；presets/ 与 run.json 均不动
try:
    for wid in work_ids:
        convert(wid, None, out, config, fmt="pdf", preset=tmp)  # 内部 --config tmp
finally:
    os.remove(tmp)
```

- 一次批量可复用同一个 `tmp`（首本生成，批量结束再删）。
- `--config` 兼容「基础配置 JSON」与「run.json 组合单」两种形态，临时文件两种都认。
- `engine` / `vertical` / `font_lang` 已支持配置回退（§8.7），随临时预设生效；
  需要临时覆盖时才加对应开关。
- `formats` 不走配置：每本用 `-f <fmt>` 指定。
- **主题槽（CSS）不在 base 配置**：临时预设改不了 CSS；临时换样式请显式
  `--pdf-docx-theme/--pdf-docx-user-theme` 或临时 run.json（`write_temp_run`）。
