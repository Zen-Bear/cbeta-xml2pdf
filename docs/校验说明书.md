# 校验说明书（面向开发 / 测试）

> 校验 = 生成档（本管线 `generate_formal` 产物）vs 官方基线（CBETA 官方 `html/docx/epub` 与 `text-with-notes` 导出）的**归一后逐字比较**。三入口共用同一校验库 `pycbeta/verify.py`。官方 plain `text`（无校注）已弃用，文本族（txt/md）一律对比 `text-with-notes`。

> **XML 版本前提**：本管线以发布版 `XML TEI P5`（`cbeta-org/xml-p5`，校勘在 `<back>` + body 锚点）为准。若误用 `P5a/P5b`（CBReader 书库 / 「單卷版」，校勘 body 内联 `<app n><lem><rdg>`），正文 base 读法只在 `<lem>`：渲染器（`render_*.py`）与辅轨 `_extract_xml_parts` 已统一「只取 lem、rdg 不进正文」，但仍会**丢 body `type="add"` 校勘注**且 `<choice>` 未完全对齐，故判为不安全源：`fetch.inspect_xml_source` 抽检 `<edition>`，GUI/CLI 告警。

> **图注**：`<figure><graphic url="…"/>` 在 txt/md 渲染为官方同款 `【圖：<文件名>】`（md 比对官方 txt，口径一致；P3 辅轨同步镜像）；docx/html 无图注文字（官方亦无，用图），保持丢弃。`normalize` 的 `【】` 剥除（≤20 字，去见证标记）对含「圖」的不剥，否则官方图注会被掩盖成缺0。

> **逐字咒文表转写**：官方 `text-with-notes` 对逐字咒文表（`<cb:tt>` 无 `place="inline"`，如 `南無颯哆喃` 的逐字）**不显示**梵文罗马字母，对 `place="inline"` 与散文（如 `此淨法界raṃ`）显示。本管线 txt/md 默认同款（`output.show_dharani_transliteration=false`），P3 辅轨镜像；docx/html 全显示（官方亦全显示）。

> **txt 尾注标记/悉昙占位**：`TxtRenderer` 正文留 `[n]` 标记、文末出 `[n] 内容`（一一对应；`show_notes=false` 全无），官方 text-with-notes 的 `[A**]/[1]` 标记在 `normalize` 中被同样剥除，故不影响比对。无法表示的悉昙字（无 roman）output `◇`(U+25C7)（官方同款），与生成侧 PUA 一起由 `normalize` 归一到 `□`。

> **悉昙读音**：官方 docx 正文/脚注均附读音（如 `歾(raṃ)`，取 charDecl `Romanized form in Unicode transcription`）；本管线 `DocxRenderer` 同款输出（读音 run 走 `latin_font`，`output.show_body_siddham=false` 可关正文显示，脚注不受影响）。官方 html 用 `<span class='ranja' roman code char/>` 空元素（CSS 显示，文本为空），本管线同款；官方 txt 用裸读音（`raṃ`），本管线 txt/md/P3 辅轨同款。`<cb:sg>` 四格式统一半角括号（如 `(音𫬠)`）。
