# 主题与样式

## 默认样式

| 格式 | 基底 CSS | 来源 | 说明 |
|------|----------|------|------|
| `html` / `epub` | `cbeta_golden.css`（可换，见 run.json） | `HtmlRenderer(base_css)` | 官方电子书样式（在线藏经样式、在线缺字库 `cbetarc`）；**纯基底，pdf_docx 主题不再追加** |
| `pdf` / `docx` | `pdf_docx.css`（可换，见 run.json） | `pycbeta/theme.py:17 _DEFAULT_CSS` → `Theme()` | 印刷主题（固定 pt 字号、版心边距、DOCX 命名样式配套）；`Theme` 默认读入 |

`Theme` 的 `tags` 只用于 docx/pdf 管线；html/epub 的 `<style>` 只有基底（+注音/灰度等管线规则）。

## 双文件分工与规则级生效范围

先摆管线事实：**PDF 不是手排的**——`IR → PDF-ready HTML+CSS → Chromium 无头打印成 PDF`
（`pycbeta/render_pdf.py:3`）。所以样式层面"HTML/PDF"是同一套（浏览器引擎解释 CSS），
"HTML 和 PDF 格式"即 `-f html` / `-f pdf` 两种输出；DOCX 是另一套（CSS 经 tinycss2 解析成
标签属性表，再翻译成 OOXML，`pycbeta/theme.py:8-9`）。`epub` 内部转调 `HtmlRenderer`
（`render_epub.py:17`），与 `html` 共用基底。

一句话记忆：**`cbeta_golden.css` 管"官方电子书样式"，`pdf_docx.css` 管"像书"**；
调打印效果（docx/pdf）改后者，且只用简单/两段选择器；`[...]` 属性选择器只对网页和 PDF 有效。

`pdf_docx.css` 是 PDF/DOCX 专用；`html`/`epub` 只用自己的基底（默认 golden），两者互不加载、互不影响。改一条规则前，先看它的选择器形状——
分水岭是 `theme.py:369 _parse_css_tags`：

| 选择器形状 | DOCX | HTML/PDF（含打印出的 PDF） |
|---|---|---|
| 简单选择器（`p.head`、`sup.note-ref`、`div.div-xu`，即 `TAG_SELECTOR` 表里的）+ 可翻译属性（字号/粗体/颜色/字体/对齐/缩进/行距/边距，`TRANSLATABLE`） | ✅ 解析进标签表 | ✅ 原样解释 |
| 两段后代 `A B`（如 `div.div-xu p.head`） | ✅ 进 compounds，祖先栈匹配 | ✅ 浏览器原生 |
| 属性选择器（`p.head[data-head-level="1"]`）、三段及以上、非可翻译声明（如 `display`） | ❌ 忽略 | ✅ 原样解释 |

实战两例（2026-09-06 实锤）：

* 标题分级 `p.head[data-head-level="1..6"]` 只影响 html/pdf；DOCX 下各级 head 一律取 `p.head`
  兜底——改这几行调不了 DOCX 字号。
* 序标题（`<head>` 在 `div-xu` 内）有专属后代规则 `div.div-xu p.head`，四格式通吃；
  要增大序的字号只改这一行的 `font-size`（HTML/PDF 侧其优先级也高于 level 规则，不打架）。

## 多格式同时

`python -m pycbeta -i in.xml -f html,docx` 按 `pycbeta/cli.py:50 render_one` 分发：

* `html` → `HtmlRenderer(theme=None)` → 仅基底（默认 golden）
* `docx` → `DocxRenderer(theme)` → `pdf_docx.css` 系（标准+增量层叠）

互不串扰；旧 `--theme` 已删除（用 `--pdf-docx-theme`/`--pdf-docx-user-theme` 替代）。

## 校验正式管线

`pycbeta/verify.py:generate_formal` 与主程序一致：`html` 纯基底，`docx` 跟 run.json 的 pdf-docx 槽。

## 自定义

* pdf/docx 换标准：`--pdf-docx-theme custom.css`（整套替换出厂全文）；加增量：`--pdf-docx-user-theme 名字`（presets/ 双目录或路径，追加）
* html/epub 换基底：`--html-epub-theme custom.css`；增量 `--html-epub-user-theme` 占位（未接线，传入只警告忽略）
* `--config run.json`：一次运行的组合单（5 槽，见下）；也接受**基础配置 JSON**（`config.user.json` / `presets/*.json`，当作 `config-json` 槽）；旧 `--theme` 与旧全量快照已废弃（报错指新格式）
* 校验：`--verify --verify-max-diff 10` 复用同一 `pycbeta/verify.py` 模块，供 `GUI` 调用

## 运行组合单（`run.json`）

* 仓库根 `run.json`（不入库，常改），不带 `--config` 自动读；没有就全出厂。模板：
  ```json
  {
    "config-json": "presets/config.user.json",
    "html-epub-theme": "cbeta_golden.css",
    "html-epub-user-theme": "",
    "pdf-docx-theme": "pdf_docx.css",
    "pdf-docx-user-theme": "my.css"
  }
  ```
* 取值（逐槽）：显式开关 > run.json 槽 > 内置默认。`config-json` 可指 `presets/` 下预设（含默认 `presets/config.user.json`；面板"设为默认"即写它），空=出厂 `pycbeta/config.json`。
* 有效配置（面板显示/CLI 输出选项共用）：出厂 `pycbeta/config.json` ← base 文件按鍵深合并（`theme.resolve_effective_config`）；出厂 `theme` 键已删除，主题唯一来源是 run.json 槽。

## 字体双栏变量（`:root` / `html[lang="zh-Hans"]`）

* 字体只此一处：`--font-标签`（如 `--font-title`，组合 `--font-div-xu-head`），规则内 `font-family: var(--font-X)` 引用；HTML/PDF 按 `<html lang>` 原生切换，DOCX 按 `Theme(lang)` 代入。
* `--font-lang zh-Hans` 切简体栏；t2s 自动切；`config.json font_sets` 已删除。

## 字号单源（`body{font-size}`）

* `body{font-size: 12pt}` 为唯一源，`p` 及无字号元素继承它；DOCX 的 em 换算、
  边距/缩进基准、文档默认字号全部锚定它（`Theme.base_pt`，只认绝对 pt）。
* **纸张 vs CSS（逐属性）**：`pages.<名>.body_font_size/body_line_height`（可选）在运行时
  **按属性覆盖** CSS body（`apply_page_typography`）：纸张写了 `body_font_size` 就覆盖
  `font-size`、写了 `body_line_height` 就覆盖 `line-height`；**没写的键回退 CSS body**。
  故 CSS body 的这两个值是**兜底**——只有纸张没写对应键（如"手机/平板"）才生效。
  入口：CLI 在 `font_scale` 之前 `apply_page_typography`；`DocxRenderer`/`PdfRenderer`
  构造时再走 `ensure_page_typography`（同一 theme 已应用则跳过，避免在缩放后重置）——
  因此**库直接调用渲染器只要传了 `page_presets` 也按纸张生效**；没传 `page_presets`
  （如 `verify.generate_formal`、默认 `DocxRenderer()`）则不动，CSS body 即源。
  **`font-family` 不受纸张影响**：纸张只管字号/行距，CSS body 的字体（`--font-body`）始终是源。
  `p` 不自带字号/行距，`p.author/translator/byline`、`div.lg`(verse) 也不带字号，都会随最终
  body 变；`title/head/juan/pin` 等自带 pt 的不随 body/纸张。
* `p.form`/`cb:def` 不再显式 `1em`（等价继承，DOCX 已有继承链）。
* 层叠：元素规则里**写了字号**就用它（覆盖 body，如 `p{font-size:10pt}`）；**没写**才继承
  body（HTML 原生继承；DOCX 无 `w:sz` → 回退 `docDefaults`=`base_pt`=body）。
  写 `em/%` 的（`p.form`/`cb:def`=1em、脚注 0.75em、注音 0.75em…）是"相对字号"，
  仍按 body 基准自动缩放（`1em`@body14 → 14pt）。其余元素同理。
* **代码兜底值（保命值）**：主题默认值之外，代码里还留有一批"CSS/配置缺失时才启用"的
  硬编码兜底（如 em 基准 12pt、文档默认 11pt、Normal 行距 1.5、页面回退 a4/25.4mm 等），
  清单见 `docs/兜底值清单.md`。
* DOCX run 继承链（外→内）：`body → div-* 祖先 → 当前标签栈全部`（`render_docx._current_tag`）；
  `docx_run` 逐 tag `update`，实现"**逐属性**从最里层往外找、最近者优先、body 兜底"。
  并列标签因此同时生效（`<lg rend="kaiti">` → 偈颂绿/字号 + 楷体），非 div 祖先
  （`li`/`item` 等）字号可下传，`body{color}` 可下传。两段与三段+后代选择器均支持
  （`theme.compounds`；三段祖先按序匹配）。
* 默认值唯一定义处 = `pdf_docx.css`：Python `DEFAULT_THEME` 已移除（此前它会
  "先打底"，导致删 CSS 键对 DOCX 无效、body 改字号传不下去）。缺省元素/关键属性由
  `theme.REQUIRED_THEME_TAGS` + `test_theme.TestRequiredThemeTags` 守护，误删会报出
  选择器并提示补回；`missing_required_theme()` 供工具复用。
* 出厂其余字号保持 pt（精确直观）；相对语义天生的（注音小字、上标、夹注、
  form/def 对齐正文）用 em；半磅一律 `round`（16pt 等 em 写法精确还原）。
* `pages.doc_size` 已删除（文档默认跟 base）。

## CBETA 校改字（`corr-cbeta`，默认关）

* `output.corr_cbeta`（默认 `false`）：`app.lem` 的**原始 `wit`** 含 `#wit.cbeta` 的正文用字标红。
  parser 把 `<anchor beg…/>用字<anchor end…/>` 区间包成 IR `E(tag="corr-cbeta")`；渲染按开关门控。
* 上色：IR tag `corr-cbeta` → `TAG_SELECTOR` 映射 `span.corr`；`pdf_docx.css` `span.corr{color:#FF0000}`
  （官方 docx 字符样式 corr）、`cbeta_golden.css` `.corr{color:red}`（官方 epub `cbeta.css`；
  **官方 html 不标红，本条属"超出官方 html"**）。CSS 编辑器左栏"CBETA校改"行可调。
* 范围：docx/html/epub/pdf（pdf 随管线）；**md/txt 不标**（`_render_e` 末尾本就透明）。
* 只包裹正文用字（`App` 在区间外，注码不变红）；与逐字校验无关（文本不变）。

## 经文资讯尾页（`p.info`）

* `【經文資訊】/【版本記錄】/【編輯說明】/【原始資料】` 几行：仿宋、行距 1。
  docx 尾页段落走 tag `info`（`pdf_docx.css` `p.info{font-family:仿宋;line-height:1}`，
  `TAG_SELECTOR["info"]="p.info"`）；pdf 尾页 `.tei-info p.info` 同规则；
  html/epub golden `#cbeta-copyright p` 同值。

## 经藏名样式（`p.series-title`）

* 规则在 `pdf_docx.css`（`font-family: var(--font-series-title); font-size: 9pt`），渲染器走主题取值；
  `config output.series_title` 仅留 `enabled` 开关，旧 `font/size` 键作回退（老用户槽不断行为）。
* 可视化编辑器"经藏名"行可调；GUI 分页卡佛典丛书名组只留开关（字体/字号按钮跳编辑器）。

## 预设库（CSS 编辑器 Schemes）

* 预设库：仓库根 `presets/`（入库随包分发）：样式 `*.css` + 配置 `*.json` 混放（按扩展名区分）+ 样张 `sample.xml`；示例 `large-print.css` 阅读大字版、`my.css` 个人样式。`pycbeta/styles/presets/` 只剩 README（内置组已退役，查找仍认旧名）。
* 文件格式 = 只存覆盖块（编辑器源码页文本），加载时出厂 + 覆盖合并
  （`theme_file_text`，层叠后胜），"设为默认"把文件名写进 run.json 的 `pdf-docx-user-theme`。
* 编辑器顶部预设行：切换只装载不写盘；启动自动载入 run.json 默认（保存按钮亮）。
