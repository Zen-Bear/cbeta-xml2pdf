# 主题与样式

## 默认样式

| 格式 | 基底 CSS | 来源 | 说明 |
|------|----------|------|------|
| `html` / `epub` | `cbeta_golden.css` | `pycbeta/render_html.py:101 base_css` | 官方金色基底，`theme=None` 时仅此 |
| `pdf` / `docx` | `pdf_docx.css` | `pycbeta/theme.py:17 _DEFAULT_CSS` → `Theme():228` | `Theme()` 默认读入，作为 `raw_css` 叠加 |

`Theme` 的 `tags`（`config.json` 逐标签）会编译为内联 `<style>` 追加在基底之后（`render_html.py:178 theme_css`）。

## 多格式同时

`python -m pycbeta -i in.xml -f html,docx` 按 `pycbeta/cli.py:50 render_one` 分发：

* `html` → `HtmlRenderer(theme=None)` → 仅 `cbeta_golden.css`（`1515b`）
* `docx` → `DocxRenderer(theme=None→Theme())` → `pdf_docx.css`（`7296b` 含标签规则）

互不串扰；`--theme custom.css` 则对两者均覆盖。

## 校验正式管线

`pycbeta/verify.py:generate_formal` 与主程序一致 `theme=None` + `load_presets:118`，`html` 仍以 `cbeta_golden.css` 生成，剥样式后正文 `4555` 字一致（`T0349` 实测 `Theme()` vs `None` 字节不等但归一化 `0/0`）。

## 自定义

* `--theme custom.css` 替换主题层（`cli.py:214`）
* `--config custom.json` 替换 `font_sets/pages/output/engines`（`cli.py:263`）
* 校验：`--verify --verify-max-diff 10` 复用同一 `pycbeta/verify.py` 模块，供 `GUI` 调用
