# 代码兜底值（保命值）清单

> **区分两个概念**
> - **默认值（主题样式）**：唯一定义处 = `pycbeta/styles/pdf_docx.css`（html/epub = `html_epub_official.css`）。属于"正常来源"。
> - **兜底值 / 保命值**：写在 Python 代码里的硬编码值，**只有当 CSS / 配置 / 数据完全没有该项时才启用**，用于保证任何输入都能出文件、不崩、不掉到 Word/浏览器的乱默认。
>
> 本文件只登记**兜底值**。新增兜底值请在本文补一行（值 / 位置 / 触发条件）。

出厂 CSS 存在时，第 1、2 节基本不会触发；第 3 节字体类多可由 `config.json` 的 `output.docx.*` 覆盖。

> 第 1 节的排版类兜底已集中到 `pycbeta/theme.py` 的 **`FALLBACKS`** 字典（只读、值恒定，新增请登记到此处）。

## 注意
- 第 1、2 节为硬性兜底，**不可由配置覆盖**；第 3 节字体/注音类多可由 `config.json` 覆盖。
- 纸张绑字号（`apply_page_typography`）只由 CLI 调用；直接调用渲染器（库/测试/校验）时不生效，见 `主题与样式.md`「纸张 vs CSS」。
